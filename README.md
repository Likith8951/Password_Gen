🔐 Password Generator

A simple and user-friendly Password Generator application built using Python. It generates random passwords using uppercase letters, lowercase letters, numbers, and special characters to help users create strong passwords.

🚀 Features

Generate random passwords.

Customize password length.

Includes uppercase and lowercase letters.

Includes numbers (0–9).

Includes special characters.

Minimum password length of 8 characters.

Simple and easy to use.

🛠️ Technologies Used

Python

Random Module

String Module
